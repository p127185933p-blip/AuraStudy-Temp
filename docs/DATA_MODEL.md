# Data Model Specification

AuraStudy 將學習計畫中的時間項目嚴格區分為兩類核心實體，並透過 AI 提案機制進行安全變更。

## 1. Deadline（截止事項）

- **語意**：具有明確期限的作業、考試或里程碑目標。
- **核心欄位**：
  - `dueDate`：截止日期／時間點（唯一時間錨點）。
  - `revision`：樂觀併發控制版本號。
- **衝突規則**：**不參與**時間區間衝突檢查。

## 2. Schedule（排程時段）

- **語意**：佔用實際學習時間的區塊行程。
- **核心欄位**：
  - `startAt`：開始時間。
  - `endAt`：結束時間（必須滿足 `endAt > startAt`）。
  - `revision`：樂觀併發控制版本號。
- **衝突規則**：**必須參與**時間區間衝突檢查。

## 3. ProposalChange（AI 提案變更）

- **語意**：AI 產生的待確認變更建議，絕不直接修改正式資料。
- **操作類型**：`create` | `update` | `delete`。
- **生命週期**：僅在使用者明確點擊「✓ Accept」後，方由 Application 層轉換為正式寫入指令。
